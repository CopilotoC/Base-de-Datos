# Base-de-Datos
Repositorio de trabajos donde se aplique GitHub y Git como sistema de versionado.
Mi base de datos busca agilizar el almacenamiento de personajes de Pathfinder. De todas formas hay algunas terminologías cruzadas de otros juegos de rol, por lo que puede llegar a haber confusiones en el nombre de las tabas. Igualmente, en cuanto se contemplan los registros de la tabla, se entiende de qué se está hablando.
Hay actualmente dos versiones del documento .sql. La primera le fakltan todas las conexiones y algunos campos, mientras que el segundo tiene las relaciones realizadas.
